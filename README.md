# Luma builds

Ready-to-install builds of a personal version of [Luma](https://github.com/ecklf/lg-luma),
the native home screen for rooted LG webOS TVs. Each release is official Luma plus a
few personal changes; the source is kept private.

This repository only holds the finished app. Releases are published automatically,
and only the last 10 are kept.

## Install with Homebrew Channel

Add this repository in Homebrew Channel's settings:

```
https://github.com/ArtinAbiri/lg-luma-builds/releases/latest/download/repo.json
```

Remove the official Luma repository first, or its releases will replace this build.
Luma's own updater (Settings > System) also checks this repository.
